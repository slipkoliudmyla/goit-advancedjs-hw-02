# goit-advancedjs-hw-02

Homework for the GoIT course "Advanced JavaScript and TypeScript", topic 4 "Asynchronous JavaScript and promises".

- `1-timer.html` — countdown timer to a chosen date ([flatpickr](https://flatpickr.js.org/) + [iziToast](https://izitoast.marcelodolza.com/))
- `2-snackbar.html` — promise generator that shows a notification after a delay

## Run locally

```bash
npm install
npm run dev
```
